## What gets fixed
- Mixed date formats → ISO `YYYY-MM-DD`
- Currency symbols / FR commas → float amounts
- Duplicate people (same email) → merged
- Inconsistent status / city casing → normalized
- Bad rows → flagged in red, not silently deleted
